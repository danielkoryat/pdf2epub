# Book Listen Android (work in progress)

Native Android 8+ companion application for the audiobooks pdf2epub makes. Books are imported once from Google Drive or the phone's files and kept in the app's private storage for offline listening. Media3 plays them in a background service with lock-screen and notification controls.

Build with Java 17, Android SDK 35, Gradle 8.11.1: `gradle -p android assembleDebug`.
On this Windows machine the Java selector workaround is required:
`JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=C:/Windows/Temp -Djava.nio.channels.spi.SelectorProvider=sun.nio.ch.WindowsSelectorProvider`

A successful debug build produces `app/build/outputs/apk/debug/app-debug.apk`. Copy the APK to your Android phone, open it and permit installation from that file manager when prompted. No Play Store listing exists.

## Version 0.2
Dark library and dedicated player, adaptive book/play launcher icon, per-book speed, accessible playback labels, and Drive import guidance. Tap Add from Google Drive, open the system picker's menu and choose Drive (installed and signed in). This uses Android's document provider; it downloads a private offline copy, not direct streaming or account-wide Drive access. Interrupted imports are not added to the library. M4B, M4A and MP3 filenames are accepted.

Phone verification checklist: install over v0.1 without uninstalling; verify icon and old books; import from signed-in Drive; cancel picker; simulate network failure during import; play offline; change speed; navigate between library/player; verify text scaling and insets on a small screen; test lock-screen controls. No connected phone was available during this build.

## Version 0.3
Persistent import panel above every screen: filename, bytes/percentage where supplied, indeterminate waiting state, stalled-provider explanation, Cancel, success/failure dismissal. Import ownership survives activity recreation within the running app process; Android process termination can still interrupt a download. No background notification or resumable download service is implemented.

Read tab highlights timed passages and supports Hebrew/RTL, seek by tapping text, embedded narration generated by the updated voice worker, and attaching matching WebVTT transcripts to existing books. Install the updated worker / redeploy it before making new books. Previous M4Bs do not gain transcript data automatically. The Android update alone does not update a hosted worker.

Design reference and provenance: design/README.md. New adaptive book/play icon. Actual embedded covers replace decorative placeholder glyphs.

## Version 0.4
- The playback service owns the listening place: it saves the position every 5 seconds while playing, on pause, seek and speed change, and when the app is swiped away, and it reopens the last book where it stopped (also after the process was killed). Headset or car play buttons resume the last book through Media3 playback resumption.
- Library: a "Continue listening" card, cover, title, author, progress and time left for every book, a small + button, and a menu on each book (Play, Play from the beginning, Delete from library, with a confirmation). Long press opens the same menu. Newly added books appear near the top.
- Listen: an empty state instead of a placeholder book when nothing is open. A thick progress bar that spans the current chapter by default (tap "Chapter / Whole book" to switch); while dragging, the times show the target and the jump. Tap a time or "Go to" to type an exact hour/minute/second. Previous/next chapter buttons, speed, sleep timer (minutes or end of chapter, fading out), chapter list.
- 15 s back and 30 s on update the screen at once, clamp at the start and end, and also appear in the system media controls and on the lock screen (replacing "previous/next track"). Headset next/previous skip the same way. MP3 files without a seek table are seekable.
- Read: the whole book's text in a scrolling list; the passage being read is highlighted and followed. Scrolling away shows "Back to now"; tapping any passage jumps there and plays. "Aa" changes the text size.
- A mini player above the tabs on Library and Read. Tapping the notification opens the app. The notification shows the author (or "Audiobook") under the title instead of "null".
- Fixed: covers crashed on Android 8-9 (MediaMetadataRetriever is not closeable before Android 10); seeking right after reopening the app did nothing until play was pressed.
- Positions and speeds saved by 0.3 are carried over.
